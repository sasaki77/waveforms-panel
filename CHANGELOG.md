# Changelog

## 1.1.0

- Add per-axis labels and configurable min/max/soft min/max for the X and Y axes
- Allow hiding series from the legend (click to isolate, ctrl/cmd-click to toggle)
- Add optional decimation for oversized waveforms
- Support showing points only, in addition to line and line+point display modes
- Read axis colors from the Grafana theme
- Keep the slider tooltip visible while dragging
- Draw waveforms with straight line segments
- Fix the panel crashing on frames that lack the selected waveform column
- Fix series names colliding when frames were unnamed, which made legend clicks affect the wrong series

## 1.0.0 (Unreleased)

Initial release.
